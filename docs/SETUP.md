# Setup

Use [Codespaces setup](GITHUB_CODESPACES_SETUP.md) or [local setup](LOCAL_SETUP.md). This session retains the Session 2 application organization and adds the `knowledge` Django app. The website, MCP server, NeMo worker, embeddings, tests and scanners share the app's one Python environment.

Start the website after migrations and account setup. Leave knowledge ingestion and indexing for Exercise 2. Ordinary ticket functionality remains available without an assistant grant; Knowledge requires explicit delegated read permission.
