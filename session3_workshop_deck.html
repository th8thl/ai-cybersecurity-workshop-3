Exercise 1

Part 1 · Learn

What is RAG?

Retrieval-augmented generation gives a model relevant source material when it answers a question.

Question

How do I recover my account?

Source

The app finds the current account recovery guide.

Answer

The model uses the guide to explain what to do next.

Part 1 · Learn

Why retrieve instead of retraining?

The account recovery policy changed. What should you update?

Use RAG for changing information

Update the policy document and refresh the search index. The same model can use the new procedure on the next request.

Fine-tune for repeatable behavior

Train on examples when you need the model to follow a consistent response format or style. Fine-tuning changes the model's weights.

Lower cost to update

Reindexing the changed material is usually cheaper than running another training job.

With RAG, the app can check who may read the policy and show which document supported the answer.

Part 1 · Learn

When can you skip RAG?

Start with the information the task actually needs.

Already in the prompt

Summarize an email the user pasted into the chat.

No outside facts

Brainstorm project names or rewrite a paragraph.

One live record

Look up a ticket and display its current status directly.

Semantic search

Search for password reset

Closer in meaning

Recover access using your credentials.

Farther in meaning

Load more paper into the printer.

Semantic search ranks text by how closely its meaning relates to the query. Related text can rank higher even when it shares none of the search words.

Part 2 · Learn

Put a puppy on a map

A vector is an ordered list of numbers. Suppose we give each phrase two made-up scores: how strongly it relates to dogs and how strongly it relates to office equipment.

  • Playful puppy → [4, 1]
  • Young dog → [3, 1]
  • Office printer → [0, 4]

Each pair gives us a point. Draw an arrow from zero to that point.

Part 2 · Learn

Which arrow points most like the puppy?

Cosine similarity compares the angle between arrows. With these made-up scores, puppy and dog score about 0.997. Puppy and printer score about 0.243.

Part 2 · Learn

An embedding is a vector learned from text

Models specialized in embeddings

Embedding models are trained specifically to turn text into vectors that can be compared.

We chose the two axes in the puppy example. An embedding model learns its coordinates during training, so phrases like playful puppy and young dog can point in similar directions.

768 numbers per input

Our embedding model, embeddinggemma:300m, converts each document passage and search query into a vector. Using the same model puts both in the same space so we can compare them.

Part 2 · Session 3 · Concepts

Where the app stores documents and vectors

  • Stores text extracted from the PDFs.
  • Tracks each document's owner, approval status, and current revision.
  • Django uses the passage IDs returned by Chroma to look up text and check access in SQLite.

The workshop uses Chroma as its vector database.

  • Stores embeddings with passage IDs and metadata.
  • Ranks passages by cosine distance from the query vector.
  • A close vector match never grants access to a private document.

Part 2 · Knowledge base

Preparing unstructured data before embedding

A PDF contains pages of text. To search for a specific answer, we prepare smaller passages first.

1. Extract text

Read the text from each PDF page.

2. Split into passages

Break longer text into chunks that search can retrieve individually.

3. Keep the source

Record the document and page for each passage so results can point back to the PDF.

The embedding model then turns each passage into a vector for semantic search.

Part 2 · Knowledge base

What is chunking?

Chunking splits document text into smaller passages so search can find the relevant part.

Original paragraph

Open settings and select Security to reset your password.

Chunk 1

Open settings and select Security

Chunk 2

select Security to reset your password.

Overlap means copying the last few words of one chunk to the start of the next. Here, both chunks contain select Security.

Search can return Chunk 2 by itself. Without overlap, it would only say to reset your password. With overlap, it also tells you which menu to select.

Part 2 · Knowledge base

Chunk size and overlap affect context

Open knowledge/ingestion.py and find chunks(). Its defaults are 100 words per chunk and 20 words of overlap. Reindex after a source or embedding-model change. Track source IDs, revisions and hashes.

Small chunks

May isolate the matching words but lose surrounding qualifications.

Large chunks

May preserve context but bring irrelevant text and hidden instructions into the prompt.

Part 2 · Session 3 · Concepts

MCP connects tools. RAG supplies evidence.

MCP · Model Context ProtocolRAG · Retrieval-Augmented Generation
PurposeStandard interface for discovering and calling tools and accessing context.Retrieve external knowledge and supply it to a model to help answer a question.
In this workshopLocal stdio call to search_knowledge with a validated delegated grant.PDF passages → semantic retrieval → evidence in the prompt → answer in plain text.
RelationshipOur RAG pipeline calls its retrieval tool through MCP. RAG can also call a database directly without MCP.

MCP does not make a tool result trustworthy. RAG does not make an answer correct. Python enforces permissions and validates returned evidence.

def accept_document(document):
    # Compare the PDF on disk with the SHA-256 hash saved at import.
    if not source_unchanged(document):
        return False

    # If page text was saved, check that it reconstructs the full saved text.
    if document.source_pages:
        page_text = '\n\n'.join(page['text'] for page in document.source_pages)
        return document.body == page_text
    return True

Exercise 7 · Concepts

Grounding and ground-truthing

Alice asks, “How do I reset my password?” The Assistant tells her to use the password recovery portal.

Grounding

Does the source support the answer?

The retrieved guide says “Use the official password recovery portal.” That passage supports the Assistant’s advice.

Ground-truthing

Is the answer correct?

Compare it with a verified reference, such as the current account recovery procedure confirmed by the support team. An outdated guide can support an answer that is wrong today.

In Exercise 7, the app checks whether the cited passage was retrieved and contains the exact quote. Deciding whether the passage supports the advice and verifying that the advice is current take separate checks.
